# Image Resizer — документація

## Призначення

Image Resizer — настільна програма для macOS, яка пакетно змінює розмір фотографій до заданого
полотна (наприклад, 1080×1350 для соцмереж). Фото масштабується за більшою стороною без обрізання,
а порожні поля заповнюються розмитою копією цього ж фото. Оригінали ніколи не змінюються: результат
зберігається поруч з ними як `<name>_<W>x<H>.<ext>`.

Програма працює повністю офлайн і не збирає жодних даних.

## Встановлення для розробки

Потрібні macOS 13+ та Node.js 20.

```bash
npm install
```

## Запуск

```bash
npm start
```

Команда збирає TypeScript (`npm run build`) і відкриває вікно програми.

## Тести

```bash
npm test
```

Модульні тести (Vitest) покривають `src/core` — логіку без залежності від Electron.

## Збірка для поширення

```bash
npm run dist
```

Докладно — у `docs/release.md`.
